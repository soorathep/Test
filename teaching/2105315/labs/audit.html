Where the data come from

Real hourly data from a gas multisensor device and a co-located reference analyzer at road level in an Italian city, March 2004 to April 2005. Columns ending in (GT) are the reference analyzer; PT08 columns are the low-cost sensors.

Source: S. De Vito, Air Quality, UCI Machine Learning Repository, doi:10.24432/C59K5F, CC BY 4.0. Paper: De Vito et al., Sensors and Actuators B 129 (2008) 750–757, doi:10.1016/j.snb.2007.09.060.

      04
      Check the AI's code
      A student asked an AI assistant: "Give me Python code for the mean CO in this file." It returned this, and it runs without an error.
      
      
      import pandas as pddf = pd.read_csv("my_air_quality.csv", sep=";", decimal=",")df = df.drop_duplicates()# mean CO concentration over the two weeksprint(df["CO(GT)"].mean())
      
      
      
        
      What is wrong with this code, and how would you notice from the printed number alone?
      
        
        
        
      Compare with the explanation
      
          
      The separator and decimal mark are right, and repeated rows are removed, so the code looks careful. It never tells pandas that -200 means missing. Every missing hour is averaged as a concentration of −200 mg/m³, so the mean is far too low, and for most files it is negative. A negative mean concentration is impossible, which is the signal a careful reader catches without opening the data.
      
          
      Fix: declare the code when reading.
      
          
      df = pd.read_csv("my_air_quality.csv", sep=";", decimal=",", na_values=[-200])
      
          
      Then check the result: count the missing values, look at the minimum, and compare one hand-calculated value with the code.

      07
      Check your understanding
      Write first, then compare.
      
      
      
        
      A colleague replaces every -200 with 0 instead of marking it missing. What happens to the mean CO, and why is it still wrong?
      
        
        
        
      Compare with the explanation
      The mean is now pulled down by every missing hour, but less dramatically than with −200, so the error is easier to miss. A zero looks like a real, clean-air reading. The analyzer did not measure zero; it measured nothing. Missing values must stay missing (NaN), and the report should state how many hours were missing.
      
      
      
      
      
        
      Removing the three repeated rows hardly moves the mean. When would repeated rows matter more?
      
        
        
        
      Compare with the explanation
      Three rows out of about 340 change a mean very little. Repeats matter more for totals (an emission summed over time is overstated), for counts of events such as hours above a limit, for anything that assumes one row per hour (resampling, time differences), and when the repeated rows fall on a peak.
