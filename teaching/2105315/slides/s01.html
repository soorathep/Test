Timestamp local or UTC? daylight saving? Tag which instrument, which unit operation. Value + unit the number means nothing without its unit. Quality the historian often says when a value is bad. A zero can be a reading or a failure.

Activity 1 · The four settings

Setting In this file If you get it wrong
Column separator ; everything lands in one column
Decimal mark , 2,6 is read as text, no mean possible
Missing value -200 −200 is averaged as a concentration
Date format day/month/year, time 18.00.00 11/03 becomes 3 November

Both missing CO rows are at 04:00. Keep that in mind: missing values may follow a pattern. The Extension view of Lab 01 asks why.

The six-check audit

1 · Shape Rows and columns as expected? 14 days of hourly data is 336 rows.

2 · Types Is every measurement a number, not text?

3 · Missing How many per column, in which code, at which times?

4 · Ranges and units Minimum and maximum physically possible? Units as documented?

5 · Repeats Any rows recorded twice?

6 · Time Does every step equal the sampling interval? Any jumps or repeats?

Run all six before any mean, plot or model. They take minutes; a wrong report takes longer.

Reading code you did not write

# 1-2  shape and typesdf = pd.read_csv("file.csv", sep=";", decimal=",", na_values=[-200])df.shape                 # (rows, columns)df.dtypes                # float64 = number, object = text# 3-4  missing and rangesdf.isna().sum()          # missing per columndf.describe()            # min, max, mean per column# 5-6  repeats and timedf.duplicated().sum()    # rows that repeat exactlyt.diff().value_counts()  # step sizes between timestamps

You do not need to write these lines. You need to read them and say what each one tells you about the file.

Four ways to check code you did not write

Count Rows before and after each step. If 3 rows vanish, you should know why.

Range Minimum and maximum against physics and units. A negative concentration is a bug.

Hand Compute one value from five rows by hand or on a calculator. Compare.

Look Plot before and after. A cleaning step should change the picture in the way you expect, and only there.

Quick prediction: the AI’s code

df = pd.read_csv("my_air_quality.csv", sep=";", decimal=",")df = df.drop_duplicates()print(df["CO(GT)"].mean())

In a file where 99 of 336 CO hours are −200 and the valid hours average 2.74 mg/m³, what does this print? Estimate it in one minute.

Studying alone: estimate the number, then go on.

It prints −57.00

(237 × 2.74 + 99 × (−200)) / 336 ≈ −57.0 mg/m³

What went wrong Separator and decimal mark are right, repeats are removed, but −200 is never declared missing. Every gap is averaged as a concentration.

The fix, and the check Add na_values=[-200] when reading. Then check: missing count 99, minimum above zero, mean 2.74.

A number can be wrong without an error message. The Range check catches this one in seconds.
