Fixed-step gradient descent

f(u,v)=(u−1)²+4(v+2)²; ∇f=(2(u−1),8(v+2)). Minimum at (1,−2).

Prediction: try α=0.1, then reset with α=0.25. A smaller objective after one step does not prove convergence. The demo stops at 200 steps or if values become too large to display.

Armijo: test a candidate before moving

Accept if f(r+αp) ≤ f(r)+c₁αgᵀp. Here p=−g.

The point and direction stay fixed during the trial loop. Only after acceptance do we move and recompute the gradient. Reset after changing inputs. Large trials outside the zoomed plot remain visible in the table.

Newton: check the direction

q(x)=(x²−1)²; g=4x(x²−1); H=12x²−4.

For descent line search, require gp<0 first. Reducing α is not a substitute for fixing an ascent direction. If g=0, classify the stationary point separately.
How to use this in class

Predict each value before clicking. In Backtracking, use c₁=0.1 and ρ=0.5: reject 1, 0.5 and 0.25; accept 0.125. After moving, repeat the search with the new gradient. The next accepted step is 0.5 and reaches the minimum for this particular example.
