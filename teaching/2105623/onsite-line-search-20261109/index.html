Before using the demo

Predict a result, test it, then explain the difference. All demos run offline in your browser. The Python lab uses only the Python standard library.

Keep this folder together. In PowerPoint, the demo links open the neighboring demo.html file. The browser slides also provide a demo button on the relevant pages. These are live-teaching slides without automatic narration.

Reference

Boyd and Vandenberghe, Convex Optimization, Chapter 9: descent methods and backtracking. Our notation uses α for step size and c₁ for the Armijo parameter.
