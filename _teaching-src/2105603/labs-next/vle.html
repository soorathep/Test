    4. Investigate the credibility of the prediction

    Master's core work

    Calculate a state in Step 1 before running either investigation.

    What these results can and cannot show

    • The half-widths you enter are assumed scenario bounds, not measured standard deviations. Each sampled range is deterministic: it is not a probability, a confidence interval or a guaranteed global bound.
    • Joint corners assume the factors vary independently. No covariance or joint error model is supplied.
    • Spread between liquid models is not a confidence interval and does not show that one model is correct. Parameters are hypothetical teaching inputs unless independently calibrated.
    • A statistical uncertainty claim needs input standard uncertainties, their covariances, a justified propagation method and coverage assumptions (NIST uncertainty propagation · NIST coverage intervals).

    A. Audit the assumptions and compare liquid models

    1. Write the equilibrium assumption used here: yiP=xiγiPisat(T).
    2. Identify which terms would change for nonideal vapor or appreciable liquid pressure corrections. All candidates below retain ideal vapor and neglected pressure corrections.
    3. Inspect the interaction parameters recorded with the calculated baseline, compare the four candidates at the same T, P and z1, and decide what independent data would be needed to select or calibrate them.
    Identify the fugacity terms that the current calculation fixes
    yiφ^iP=xiγifiL,*(T,P)

    The vapor-mixture fugacity coefficient represents vapor nonideality. The pure-liquid reference fugacity includes the saturated-vapor and liquid pressure corrections. This Lab sets the vapor coefficient and those pressure corrections to one, giving the simpler equation above. Changing only the liquid activity model does not test those assumptions.

    B. Examine bounded input and property sensitivity

    1. Enter an assumed half-width for each factor. Start with the illustrative values below and explain why they are useful for this exercise.
    2. Run ten one-at-a-time scenarios and 32 signed joint corner combinations. Read failed and indeterminate scenarios as well as finite results.
    3. Compare the positive and negative one-at-a-time responses. Explain whether their asymmetry supports a local linear approximation.
    4. Repeat near the bubble boundary at 96 kPa. A change in phase branch makes unqualified linear uncertainty propagation unreliable; these finite scenario changes are not automatically local derivatives.
